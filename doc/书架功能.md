# 书架功能

## 需要一个书架功能

管理我们的书。配置 `bookshelf_dir` 后，这个目录就是用户主动维护的书架目录：

- 所有 `reader add <file>` 和 `reader <file>` 直接打开的书都会进入这个目录。
- 配置书架前已登记在外部目录的旧书，在下次打开或再次导入时也会复制进托管目录；目录外不会生成 sidecar。
- 每本书同级生成一个 `*.json` sidecar，记录标题、作者、进度、书签、最近打开和 missing 状态。
- 用户也可以直接把 `.epub` / `.txt` / `.pdf` 放进书架目录，然后执行 `reader shelf refresh [目录]` 主动全量对比更新；首次传入目录时会同时持久化为 `bookshelf_dir`，以后可省略。
- `reader shelf refresh` 递归扫描书架目录，新增书会导入，已有书会更新元数据并保留进度，缺失文件会标记为 `missing: true` 而不是删除记录。
- sidecar 如果没有对应书文件，也没有 library 记录，则视为孤儿并清理。
- 刷新只做文件与元数据对账，不改变最近阅读书籍；只有真正打开书籍才更新 `resume`。
- `library.json`、`configuration.json` 和 sidecar 都先完整写入同目录临时文件，再原子替换旧文件。
- 已配置的书架目录不存在、不是目录或不可读时刷新直接报错，不能伪装成零变更成功。
